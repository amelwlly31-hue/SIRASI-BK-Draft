SIRASI-BK – Draft Sistem

Cara menjalankan:
1. Simpan folder SIRASI-BK di C:\xampp\htdocs\
2. Jalankan MySQL melalui XAMPP.
3. Import database sirasi_bk.sql melalui phpMyAdmin.
4. Buka folder SIRASI-BK di VS Code.
5. Buka Terminal, lalu jalankan:
   php artisan serve
6. Buka alamat yang muncul di browser.
